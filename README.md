# Haven TV Launcher website

Official product website for [Haven TV Launcher](https://github.com/sudharsan-ak/haventv-launcher), a customizable, ad-free home screen for Android TV and Google TV.

Built with Next.js, React and TypeScript, statically exported.

## Screenshot credits

Product captures were taken from the actual launcher. Some screenshots show third-party media artwork and photographic wallpaper sources (including Bing and Earth View).
